# ADR 0009: Product Sizing and Unified Line Item Contract

The catalog contains Stripes, Fullsleeve, Drsleeve, Printed tees, Ringer tees, Henley, Trackpants, and Sweatpants. Tops use alpha sizing while Trackpants and Sweatpants may use numeric waist sizing. Each purchasable variant has one selected size on its order line, keeping the cart and checkout contract consistent across tops and bottoms.
